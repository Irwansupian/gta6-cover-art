**Vice Panel Studio** is an offline web app that turns your own photos into bold, multi-panel GTA-style poster cover art and exports it as a PNG. Everything happens in the browser — no uploads, no server, no build step.

- **Five layouts** — the iconic nine-panel 3×3 grid, a tall hero panel with three stacked panels, 2×2, 2×3, and a full-bleed hero with a bottom strip of three.
- **Any photos** — load as many as you like into the tray, click a panel and a photo to assign it, fill every panel with one photo, then drag on a panel to reposition and use the zoom slider to crop tighter.
- **Four grades**, applied as real per-pixel canvas work: Sunset Gradient Map (purple → orange → warm cream), Neon Nights (teal-pink split), Golden Hour (warm lift) and Vice Pastel (soft pink-teal), plus optional film grain and vignette, white keylines and inner shadows on every panel.
- **Lettering** — a big condensed title in Anton with a sunset gradient fill and heavy outline, a glowing neon script subtitle in Pacifico, and an invented starburst studio badge drawn in canvas. All wording is editable; everything is original, with no logos or trademarks.
- **Exports** at 1080×1080, 1080×1350 or 1920×1080 PNG, rendered by the same code path as the live preview.

## Run it

```sh
node serve.ts
```
then open http://localhost:8080 in a desktop browser.
